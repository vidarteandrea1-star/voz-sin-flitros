# Voz Sin Filtros

## Hablar también es cuidarse

### Descripción
Voz Sin Filtros es una plataforma digital orientada a estudiantes universitarios que busca brindar apoyo emocional accesible, anónimo y basado en evidencia.

### Problema
Los estudiantes universitarios enfrentan ansiedad, estrés y depresión, pero encuentran barreras como el estigma, los costos y la falta de acceso a apoyo psicológico oportuno.

### Solución
La plataforma ofrece seguimiento emocional, apoyo comunitario y recursos especializados para promover el bienestar mental de los estudiantes.

### Público objetivo
Estudiantes universitarios que enfrentan ansiedad, depresión, estrés académico o barreras para acceder a apoyo en salud mental.

### Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Firebase
- Chatbot con IA
